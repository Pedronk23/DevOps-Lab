# Contribuir

Este es un cuaderno personal, así que no busco aportaciones de contenido nuevo.

Lo que sí agradezco mucho:

- **Correcciones**: si algo está mal, desactualizado o es directamente una mala
  idea, abre una issue o un PR. Mejor si incluyes la versión con la que lo has
  probado.
- **Matices**: "esto funciona pero rompe X" es información valiosa.

## Antes de abrir una issue

Indica qué nota concreta es y con qué versiones lo has reproducido.
