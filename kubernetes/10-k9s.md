# K9s

Interfaz de usuario para terminal (TUI) que permite observar y gestionar clústeres de
Kubernetes en tiempo real. Funciona como una capa interactiva sobre `kubectl`, actualizando
la información automáticamente sin ejecutar comandos.

- **Arranque**: `k9s` en la terminal.
- **Salir**: `q`

## Navegación general

| Tecla | Acción |
|---|---|
| `:` | abre el prompt de comandos para cambiar de recurso |
| `Enter` | entrar en el recurso seleccionado |
| `Esc` | volver atrás |
| `↑ ↓` | moverse por la lista |
| `Ctrl + A` | muestra todos los alias disponibles |
| `?` | ayuda contextual |
| `q` | salir de K9s |

## Cambiar de recurso con `:`

| Comando | Recurso |
|---|---|
| `:pods` | pods |
| `:deployments` | deployments |
| `:services` | services |
| `:ingresses` | ingresses |
| `:nodes` | nodos |
| `:namespaces` (`:ns`) | namespaces |
| `:configmaps` | configmaps |
| `:secrets` | secretos |
| `:pvc` | persistent volume claims |
| `:events` | eventos |
| `:crds` | custom resource definitions |
| `:ctx` | contextos (cambiar de clúster) |
| `:wk` | workloads |
| `:cronjob` | cronjobs (para ver los jobs generados) |

## Filtro y búsqueda

| Tecla | Acción |
|---|---|
| `/` | filtra por nombre dentro de la vista actual |
| `Esc` | limpia el filtro |
| `Ctrl + S` | guarda el filtro como búsqueda |

> El filtro es en tiempo real y acepta expresiones regulares.

## Acciones sobre recursos

| Tecla | Acción |
|---|---|
| `l` | ver logs del pod seleccionado |
| `s` | abrir shell dentro del contenedor |
| `d` | describir el recurso (`kubectl describe`) |
| `e` | editar el recurso en YAML |
| `y` | ver el YAML completo del recurso |
| `x` | ver decodificado (útil para Secrets) |
| `f` | aplicar port-forward |
| `r` | forzar refresco de la vista |
| `Ctrl + D` | eliminar el recurso seleccionado |
| `Ctrl + K` | forzar eliminación (kill) |

## Dentro de los logs

| Tecla | Acción |
|---|---|
| `f` | activar/desactivar follow (tiempo real) |
| `w` | activar/desactivar word wrap |
| `s` | guardar logs a fichero |
| `t` | mostrar timestamps |
| `0-9` | cambiar entre contenedores del pod |
| `/` | buscar texto en los logs |
| `Esc` | volver atrás |

## Contexto y clúster

| Comando | Acción |
|---|---|
| `Ctrl + R` | rotar entre los contextos configurados en el kubeconfig |
| `:contexts` | ver y cambiar contextos disponibles |
| `:users` | ver usuarios del kubeconfig |
| `:pulses` (`:pu`) | visión general del estado del clúster |
| `:xray` | árbol de dependencias entre recursos |
